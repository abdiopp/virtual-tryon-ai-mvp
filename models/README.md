# Models Directory

This folder stores downloaded and trained model artifacts.

Expected examples:

- `models/huggingface/` for Hugging Face cache snapshots
- `models/leffa/` for the cloned Leffa repository
- `models/leffa_ckpts/` for Leffa checkpoints and preprocessing weights
- `models/fashn_vton/` for cloned FASHN VTON repository
- `models/fashn_weights/` for FASHN VTON model + DWPose files
